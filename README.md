# Auto Parts Inventory & POS Management System

Web-first SaaS-ready inventory and POS application for bike spare parts shops.

## Project Structure

- backend/ - .NET 8 Web API using Onion Architecture
- web/ - Next.js web application
- docs/ - Claude/vibe coding documentation

## Build Order

1. Documentation setup
2. Backend foundation
3. Web foundation
4. Auth and shop
5. Master data
6. Product and inventory
7. POS billing
8. Purchase bill OCR
9. Returns and payments
10. Reports
11. PWA/offline
12. Future mobile
